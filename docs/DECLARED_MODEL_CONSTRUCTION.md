# Caller-authored low-level models

Pinned oracle: Pele1.6.0, source458322a5b8abb1ae57ddf127c32017ab9fb14a92. The native public registry exposes `schema_for(id)` and `create_from_graph_as(id, graph, config)`; `PublicDocument::from_graph(module, graph, config)` supports consumer modules. Each module opts into its concrete state constructor. The default rejects unavailable construction. Schema/graph budgets and references are checked before the constructor, and the resulting document retains the actual registration. No source is reconstructed or parsed.

After `await loadDiagramEntries()`, all33 per-diagram `render(model, config, options)` entries also accept ordinary caller-authored models. The existing graph bridge retains the caller's objects, Maps, Sets, Dates, functions, own descriptors, extra fields, UTF16 strings, IEEE values and cycles. Native codecs import renderer inputs into their existing concrete model; existing Rust renderers perform layout and SVG generation. Raw model ownership remains distinct from high-level `core.parse` provenance. Dispose adopted models with `disposeDiagramModel(model)`. Disposed models retain a weak tombstone and cannot be implicitly adopted again by raw rendering.

Per-entry `RenderModel` types select the pinned declared model fields. `parse()` still returns the richer mutable database type with its real methods. The fixture constructs ordinary roots with only declared fields plus explicit caller extras. It hydrates literal data directly in the browser; entry parsing is disabled during the rendering proof. Gantt's caller-defined `getTasks` returns already scheduled literal tasks with shared Date objects. Its execution uses the native active-model callable interface, without substituting the database scheduler.

The pinned declarations omit helpers some low-level renderers actually read. This implementation preserves those failures: grouped Flowchart/Swimlane reads `subgraph`; ordinary AgentFlow vertices read `vertexKind`; C4 relations read `getC4Shape` after layout measurements; State reads its undeclared cached `graph.nodes`; Gantt exclusions read `isInvalidDate` after earlier drawing measurements. It does not inject database prototypes, private parser bookkeeping, or cached graphs. AgentFlow uses the actual native graph builder for fresh data and retains its successful first-render cache, matching the pinned WeakMap ownership. Missing helpers fail at the relevant operation boundary.

Canonical native TypeError diagnostics are pinned to the npm oracle. Browser intrinsic error prose and minified variable diagnostics are recorded separately in attached `fresh-model-intrinsic-diagnostics.json` artifacts for these fixed failure vectors; the native canonical message, exception class, complete partial model, callback order and SVG remain asserted. PeleError fields remain exact. Function intrinsic metadata is compared to the same live browser observer; the Node fixture retains its original observations, while data-object property order/presence/flags remain exact.

This slice does not provide arbitrary class constructors, a JavaScript property interpreter, arbitrary custom prototypes/getters, or dispatch of every undeclared helper override. Existing active malformed-UTF16 drawing and other per-codec limits remain documented separately. A declared plain model can expose an upstream missing-helper error; accepting its graph does not fabricate successful rendering.

Proof is feature integration:67 pinned all33-family literal/edited/error vectors, a downstream no-parser provider factory with registration replacement/drop and graph validation, and packed browser literal identity/error/recovery/disposal checks. The generator records source/dist hashes, full before/after graphs, exact SVG/dimension bits, and ordered host callbacks. Transport is independently bounded; the factory does not relax source/output/graph budgets.
