## Shared Rust flowcharts for Swift and web

Independent MIT Rust adaptation inspired by Pele. One engine parses Mermaid
flowchart source, lays out graphs, routes edges and returns outlined SVG plus
versioned geometry.

- Five node shapes, TB/TD/BT/LR/RL directions, solid/dashed/thick links and labels.
- Forks, joins, skip edges, cycles, self-loops, parallel links, disconnected nodes.
- Bundled Noto Sans shaping and paths: no installed fonts or web view.
- Owned C results, typed Swift package, browser WASM/npm package and playground.
- Bounded work, structured errors, explicit unsupported-syntax rejection.

Verified through public interfaces, packaged Rust/npm consumers, SwiftPM, AppKit
pixels, arm64/x86_64 C ABI and Chrome/Firefox/WebKit. Ten rendered and twelve rejected
fixtures match native/WASM results. [Verification](https://github.com/vijayksingh/pele-rs/blob/v0.1.0/docs/VERIFICATION.md).

### Downloads

- `CPele-macos-universal.xcframework.zip`: macOS 14+, arm64/x86_64; root SwiftPM package.
- `unlocalhosted-pele-rs-0.1.0.tgz`: JavaScript, types and WASM package.
- `pele-rs-0.1.0.crate`: pure Rust engine, embedded font and notices.
- `SHA256SUMS`: archive hashes. `verification.json`: release evidence summary.

README includes install examples and real WASM playground GIF. Packages distributed
here; not published to crates.io/npm registry yet.

### Scope

Documented flowchart subset, **not full Mermaid/Pele compatibility**. Subgraphs,
styling, rich text, callbacks/links/images, other diagrams, font fallback and bidi
deferred. Layout differs from Pele; outlined text is not selectable. Intel checked
under Rosetta; no physical Intel/macOS 14 or mobile Safari proof.
Engine MIT; bundled font SIL OFL 1.1.
